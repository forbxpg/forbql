# forbql

**The SQL firewall for AI agents.** Let agents query SQLite, PostgreSQL and MySQL under
your policy: read-only execution, allowlists, PII masking and a tamper-evident audit log.

> **Status: pre-alpha.** v0.1 is being built in the open. Nothing is released yet, and
> nothing here is a promise until it ships with a test against a live database.

- Library first: `pip install forbql`, then the MCP server and CLI on top of it.
- Security reports: see [SECURITY.md](SECURITY.md). Contributing: [CONTRIBUTING.md](CONTRIBUTING.md).
